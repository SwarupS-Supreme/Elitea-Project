# Elitea-Project
This project is to test Elitea Integration with GitHub.

## Troubleshooting

If a search returns `Unable to find anything using query`, verify the query syntax and the target space/key first.

Example checks:
- Confirm the `space` value is correct.
- Confirm the title filter is valid and matches existing pages.
- Avoid overly restrictive combinations when searching for `type=page` and `title~"EPAM"`.
- Re-run the search with a narrower query first, then add filters gradually.
