# Elitea-Project
This project is to test Elitea Integration with GitHub

## Playwright E2E Automation

This repository includes Playwright automation for EPAM Services navigation covering:
- TC_1: Client Work text visibility
- TC_2: CONTACT US text visibility
- TC_3: Partners text visibility

### Run

```bash
npm install
npx playwright install
npm run test:e2e
```
